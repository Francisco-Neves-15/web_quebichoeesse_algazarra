# Run Comands

## Run project as a Dev: 
`npm run dev`

## Check ESLint problems:
`npm run lint`

## Format the code with Prettier:
`npm run format`

## Nota:
O script `npm run format` não funciona porque o Prettier não está instalado como dependência. Para corrigir, você pode:
- Instalar Prettier: `npm install --save-dev prettier`
- Depois disso, o comando `npm run format` funcionará normalmente
